# ACHEEL — Cartographies interactives · V2

Cette branche contient la version livrable destinée à l’équipe Audit pour identifier et qualifier les points de contrôle.

## Télécharger et ouvrir

- [Fichier HTML autonome](dist/acheel-cartographies-v2-points-controle.html) : ouvrez le fichier sur GitHub, puis utilisez **Download raw file / Télécharger le fichier brut**. Enregistrez-le avec l’extension `.html`, puis ouvrez-le dans Chrome ou Edge.
- [Archive ZIP V2](dist/acheel-cartographies-v2.zip) : téléchargez l’archive et extrayez-la. Elle contient le portail, les données, les originaux et la documentation.

Le HTML autonome réunit l’interface et les données ; il fonctionne sans installer de logiciel ni lancer de serveur. Son ouverture directe dépend des règles de sécurité de votre poste et de votre navigateur.

## Usage

Dans l’accueil, cliquez sur **Identifier les points de contrôle**. La V2 distingue les mentions déclarées dans les sources, les propositions et les questions à confirmer. Elle présente 491 mentions ou questions, sans les assimiler à 491 contrôles indépendants ou effectivement réalisés.

Les 102 processus sont conservés. Pour chaque point, consultez le processus et les risques cités, puis qualifiez si nécessaire le responsable, le risque précisément rattaché et les preuves attendues. Les qualifications sont locales au navigateur ; exportez-les en JSON pour les conserver ou les transférer. Le CSV porte sur les points filtrés.

La cartographie **Outils ACHEEL** reste indiquée « À venir ». Les données sont internes : conserver le contrôle d’accès du dépôt et utiliser un hébergement privé pour un déploiement.

Les autres fichiers de développement et la V1 restent conservés dans l’environnement de travail. Aucun déploiement public n’est effectué par cette livraison.
